# 胡桃卡牌 v11 最终总表（83 张 · 卡名不变）

## 系统回顾

| 系统 | 规则 |
|---|---|
| **血梅香** | 每层：你每次命中 +1 伤害；每回合开始 -2 层 |
| 阈值 | ≥6「落梅」攻击命中后抽 1（每回合最多 2 次）。v11.2 起取消 ≥4 加伤与 ≥10 引爆翻倍 |
| **还阳 X** | 弃牌堆顶 X 张 → 抽牌堆顶，并赋予「灵」 |
| **灵** | 带灵牌打出时强化一次（攻击 +50% / 技能 +1 层 / 费用 -1）；打出后转为「灵·已消耗」（仍算「带灵牌」） |
| **轮回** | 回合开始获得 2×层数 格挡，然后层数减半；无上限 |

**不做**：金币、纯 X 伤害、力量成长、召唤物、充能球。（v11.3 起把「消耗」用作群伤/群体铺层的代价，不再排斥）

## 资源分配（v11 强化）

**能量来源（6 处）**：血偿契约(+2)、献祭薄礼(+1)、薪尽火传(+2)、往生诀(+1)、阴阳两界(+1)、命途逆旅(灵牌回能)

**抽牌（15 处，只列无条件的固定抽牌来源）**：烛火摇曳(2,弃2)、蝶眠(2)、暗香浮动(1)、血梅前调(1)、梅影重重(1)、晨露(1)、灯枯之际(3)、命途逆旅(2)、葬仪对策(1)、往生诀(2)、落梅(每回合 2)

目标：增加「群体挂印记」和「群体伤害」的手段，并把最强的群体牌用「消耗」定价。

### 变成群体（AoE）
| 卡 | 改动 |
|---|---|
| 血梅香径 | 0 费单体 +3 层 → **0 费对所有敌人 +2 层**（升级 3） |
| 蝶舞 | 单体 3 伤 ×2 → **对所有敌人 3 伤 ×2**，仍还阳 1（升级 4×2） |
| 千蝶振翅 | 单体 2 伤 ×3 → **对所有敌人 2 伤 ×3**，仍还阳 2（升级 3×3） |
| 花开彼岸 | 单体 +3 层 → **获得 6 格挡 + 对所有敌人 +1 层**（升级 9 格挡） |
| 梅香疾冲 | 单体 7 伤 → **对所有敌人 5 伤**，抽 1 弃 1（升级 7） |

### 加「消耗」（作为群体强度代价）
| 卡 | 改动 |
|---|---|
| 焰蝶焚野 | 9→**10** 伤（升级 13）+ **消耗** |
| 蝶火燎原 | 12→**14** 伤（升级 17）+ **消耗** |
| 千朵赤团 | **消耗**（数值不变） |
| 焚香祭礼 | **消耗**（数值不变） |

### 机制补充
- `BlossomStrikeAll` 现在支持多段攻击、每段挂层、以及对每个敌人各自结算落梅阈值抽牌，
  AoE 攻击卡与单体攻击卡走同一套血梅香结算逻辑。
- 新增的「消耗」使用游戏原生 `CardKeyword.Exhaust`，卡面会自动追加金色「消耗。」

## v11.4 群体牌去重复

原来「血梅香径 / 鬼门开 / 花开彼岸 / 雪霁梅香」几乎都是「对所有敌人施加 N 层血梅香」，
只差 1~2 层数值，抽牌也是同一档。这一版把它们拆到不同的轴线上：

| 卡 | 新定位 | 效果 |
|---|---|---|
| 血梅香径（0 费） | 唯一的纯群体铺层 | 对所有敌人 +2 层（升级 3） |
| 蝶群戏梅（1 费） | 铺层 + 轮回 | 对所有敌人 +2 层，获得 1 层轮回（升级 3） |
| 鬼门开（1 费） | **减伤 / 控制** | 对所有敌人 +1 层血梅香，并施加 1 层虚弱（升级 2） |
| 花开彼岸（1 费） | **防御 + 顺带铺层** | 获得 6 格挡（升级 9），对所有敌人 +1 层 |
| 雪霁梅香（1 费，稀有） | **群体铺层 + 过牌** | 对所有敌人 +2 层（升级 3），抽 2 |
| 蝶引千夜（2 费） | 大量铺层 + 轮回 | 对所有敌人 +3 层，获得 2 层轮回（升级 4） |

引入了原版机制：**虚弱**（原版 `WeakPower`）、**格挡**，不再所有群体牌都只发血梅香。

## v11.5 蝶引来生结算顺序

| 项 | 改动 |
|---|---|
| 效果 | 失去 2 生命 → 对目标施加 3 层血梅香 → **最后造成 3 点伤害** |
| 升级 | 失去 1 生命 → 4 层 → 6 伤害（通用升级 +3 伤害） |
| 伤害性质 | 固定值，不吃血梅香「每层 +1」的加伤（它不是攻击牌） |
| 原因 | 让卡面文字顺序与结算顺序一致：伤害永远在铺层之后落地 |

## v11.6 抽牌牌去重复

问题：**晨露（0 费抽 2）/ 烛火摇曳（0 费抽 2 弃 1）/ 灯枯之际（1 费抽 2）** 都是「抽 2」，
而且 **蝶眠 与 梅影重重 完全同效**（都是 1 费 7 格挡 + 抽 2，连升级都是 10）。

| 卡 | 旧 | 新 | 新定位 |
|---|---|---|---|
| 晨露（0 费） | 抽 2 | 不变（升级 3） | 唯一的**纯过牌**基准 |
| 烛火摇曳（0 费） | 抽 2 弃 1 | 抽 2 弃 1 + **消耗** | 一次性**滤牌** |
| 灯枯之际（1 费） | 失 3 血 + 抽 2 + 1 能量 | 失 3 血 + **2 能量** + 抽 1（升级 失 2） | **生命换能量**的爆发 |
| 蝶眠（1 费·普通） | 7 格挡 + 抽 2 | 不变（升级 10） | 可重复的**格挡 + 过牌** |
| 梅影重重（1 费·罕见） | 7 格挡 + 抽 2（与蝶眠完全同效） | **10 格挡** + 抽 2 + **消耗**（升级 13） | 一次性**大格挡 + 过牌** |

原则：同一「抽 2」量级下，靠**费用 / 生命代价 / 消耗 / 次要效果**四条轴区分，
避免出现「同费同效、只有稀有度不同」的牌。

## v11.7 工具牌重做（贴合卡名 + 对齐原版数值）

参照 sts2 原版数值：**1 费攻击中位 8 伤、1 费格挡中位 6 格挡**；
「0 费抽 2」在原版属于稀有档（多数 0 费只抽 1），**1 费抽 3** 才是罕见牌基准（Skim / Acrobatics）。

| 卡 | 旧 | 新 | 依据 |
|---|---|---|---|
| 晨露（0 费） | 抽 2（升级 3） | **抽 1 + 3 格挡**（升级 6 格挡） | 对标原版「灵巧」0 费抽 1 小护身 |
| 烛火摇曳（0 费） | 抽 2 弃 1 + 消耗 | **抽 2 弃 2**（升级 抽 3 弃 2） | 换手不增手牌，比「消耗」更贴「摇曳」 |
| 灯枯之际（1 费） | 失 3 血 + 2 能量 + 抽 1 | **失 3 血 + 抽 3**（升级 失 2） | 对标 Skim（1 费抽 3）+ 失血代价 |
| 蝶眠（1 费） | 7 格挡 + 抽 2 | **8 格挡 + 结束你的回合**（升级 12） | 名字就是「眠下去」，把回合交出去换护身 |
| 梅影重重（1 费） | 10 格挡 + 抽 2 + 消耗 | **8 格挡 + 抽 1**（升级 11） | 对标「势不可挡」8 格挡 + 抽 1 |
| 血梅前调（1 费） | 2 层 + 条件抽 2 | **2 层 + 抽 1**（升级 3 层） | 去掉条件抽 2 的手牌膨胀 |
| 香满襟（1 费） | 2 层 + 3 格挡 + 抽 1 | **3 层 + 3 格挡**（升级 4 层 / 6 格挡） | 去掉抽牌，专注铺香兼护身 |

「结束回合」用的是原版 `PlayerCmd.EndTurn(Owner, false, null)`，
和原版虚空形态（VoidForm）的写法一致：先把自身效果结算完，再交出回合。

## v11.8 其余工具牌重做（名字 → 独有效果 + 原版配合）

| 卡 | 旧 | 新 | 配合的原版机制 |
|---|---|---|---|
| 宴罢人散（1 费） | 失 3 血 + 10 格挡 + 抽 1 | **弃掉所有手牌；每弃 1 张获得 3 格挡**（升级 4） | 弃牌（配合还阳/灵：主动把手牌送进弃牌堆） |
| 葬仪对策（1 费·稀有） | 7 伤，≥6 层还阳 2 + 抽 1 | **8 伤 + 2 层易伤**（升级 11 / 3 易伤）；目标有血梅香则抽 1 | **易伤**放大后续全部伤害 |
| 往生堂名录（1 费） | 还阳 2 + 抽 1 | **保留；还阳 2 张**（升级 3） | **保留**：名册一直带在手上 |
| 棺材铺日课（1 费） | 3 层轮回 + 抽 1 | **获得 3 层轮回；保留**（升级 4） | **保留**：日课天天都能做 |
| 命途逆旅（1 费） | 抽 2 + 灵牌回能 | 不变 + **[gold]虚无[/gold]**（升级 抽 3） | **虚无**：逆旅短暂，回合末没用掉就散 |
| 大红大紫（X 费·稀有） | 抽 X+1、还阳 X、1 能量 | **对所有敌人造成 5 伤害 X 次**（升级 6） | 原版旋风斩式的 X 费多段 AOE |

设计口径：
- **每个名字给一个独立机制**：宴罢人散→弃手牌、葬仪对策→易伤、往生堂名录/棺材铺日课→保留、
  命途逆旅→虚无、大红大紫→X 费多段群伤，不再都是「抽 1~2 + 小效果」。
- **抽牌配额进一步收敛**：宴罢人散、往生堂名录、大红大紫都不再抽牌；能量来源从 7 处降到 6 处。
