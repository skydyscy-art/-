# 胡桃卡牌 v9 总表（83 张 · 卡名不变）

## 一、四个系统

| 系统 | 规则 |
|---|---|
| **血梅香** | 目标每 1 层，你每次命中额外 +1 伤害；每回合开始 -1 层 |
| **阈值** | ≥4 层「落梅」：攻击命中时额外造成「层数÷2（上取整）」伤害，每张攻击卡一次<br>≥6 层「采撷」：攻击命中抽 1，每回合最多 2 次<br>≥10 层「绽裂」：引爆类卡伤害 ×2 |
| **还阳 X** | 弃牌堆顶 X 张 → 抽牌堆顶，并赋予「灵」 |
| **灵** | 带灵的牌打出时强化一次：攻击 +50% 伤害 / 技能 +1 层 / 费用 -1；打出后消失 |
| **轮回 X** | 获得 X 格挡；回合结束时轮回 ×0.5（向下取整，最低减 1）；回合结束时**保留 2×轮回 点格挡**（无硬上限） |

**明确不做**：纯 X 伤害（旋风斩式）、力量成长、消耗引擎、召唤物/充能球。

# 附录：v10 定稿修订

## A. 名词统一
- 取消「转生」，攻防两种用途统一叫 **轮回**
- 卡面写法：`消耗 X 层轮回：造成 3X 伤害`

## B. 轮回最终规则
| 项 | 规则 |
|---|---|
| 获得 | 还阳 1 张 → +1 层；部分卡直接给 X 层 |
| 效果 A · 守 | 回合开始时获得 **2×轮回** 格挡（等价于跨回合留存） |
| 效果 B · 攻 | 消耗 X 层 → 每层 **3 伤害** |
| 衰减 | 回合开始 **层数减半**（向下取整） |
| 上限 | **无** |

## C. 成长钩子（无限的可能性，全部保留）
| 钩子 | 卡 | 作用 |
|---|---|---|
| ① | 生人勿近（1费能力） | 每打出 1 张带灵牌 → +1 层轮回 |
| ② | 万夫莫敌（3费能力） | 回合结束若轮回 ≥3 → 抽 1 |
| ③ | 香如故（3费能力） | 每回合第一张带灵牌打出后，灵不消失 |
| ④ | 殓骨还乡（2费攻击） | 击杀后本卡还阳回牌堆顶（带灵） |
| 无限入口 | 命途逆旅 X | 抽 X+1，每抽到带灵牌 +1 能量（能量闭合的唯一口子） |
