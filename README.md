# HuTaoMod —— 杀戮尖塔2 胡桃角色 Mod

为《Slay the Spire 2》添加可玩角色「胡桃」（往生堂第七十七代堂主）的原创 Mod。
基于社区模组库 [BaseLib](https://github.com/Alchyr/BaseLib-StS2) 开发，美术素材为 AI 原创生成（手绘暗黑奇幻风），不含任何游戏内部素材。

## 核心机制

### 血梅香（v2）

胡桃的专属减益：**目标每受到一次攻击伤害，每层血梅香使其额外受到 1 点伤害**——多段攻击每段命中各结算一次，层数不会随回合自行衰减。

- **铺层**：攻击/技能卡施加层数（血梅香径、花开彼岸、焚香祭礼……）
- **增伤**：胡桃所有攻击卡命中带层目标时自动结算加伤（统一入口 [BlossomSupport.cs](HuTaoMod/Code/Cards/Support/BlossomSupport.cs)，基础伤害走原版攻击管道吃力量/易伤）
- **引爆**：消耗全部层数，一次性按「每层 X 点」结算（赤团华绽、千朵赤团、蝶引魂归）

### 三大流派

| 流派 | 核心思路 | 关键卡 |
|---|---|---|
| **血梅香流** | 铺层 → 增伤放大 → 引爆收割 | 血梅香径、彼岸归途、淬刃梅香、赤团华绽、千朵赤团、梅雪聚散 |
| **烧血流** | 主动烧血换资源 → 低血线收益 → 回血续航 | 血偿契约、阴阳两界、宴罢人散、生死边缘、向死而战、天命有归 |
| **力量流** | 烧血攒力量 → 力量化爆发 | 往生堂训、威仪天下、吾身即薪、阴阳要诀、葬仪对策、狂杀 |

三流派天然咬合：**烧血**是血梅香卡与力量卡共同的支付手段；**力量流攻击同样吃血梅香加伤**（BlossomStrike 统一结算）；**低血线**既是烧血流的代价，也是生死边缘/向死而战/往生诀的燃料。

## 下载与安装（玩家）

1. 到本仓库的 **Releases** 页面下载最新的 `HuTaoMod-vX.Y.Z.zip`
2. 安装前置 **BaseLib 3.4.7+**（[Releases](https://github.com/Alchyr/BaseLib-StS2/releases)）
3. 把压缩包里的 `HuTaoMod` 文件夹解压到 `Slay the Spire 2/mods/`
4. 启动游戏，在角色选择里选「胡桃」

> 也可以下载带前置的一体包（`*-含BaseLib.zip`），把这一个包里的 `BaseLib` 和 `HuTaoMod` 一起放进 `mods/` 即可。

## 环境搭建（Windows）

1. **安装 .NET SDK 9.0 或更高**：https://dotnet.microsoft.com/download
2. **下载 MegaDot 4.5.1**（Mega Crit 定制版 Godot）：https://megadot.megacrit.com
   解压到任意目录，例如 `C:\megadot\`。**注意：版本必须是 4.5.1，更新的版本会导致游戏无法加载 pck。**
3. **安装《Slay the Spire 2》**（Steam 正版，需要游戏内的 `sts2.dll`、`0Harmony.dll`）。
4. **安装 BaseLib**（游戏内前置 Mod）：
   - 首选：Steam 创意工坊订阅 [BaseLib](https://steamcommunity.com/sharedfiles/filedetails/?id=3737335127)
   - 备选：从 [GitHub Releases](https://github.com/Alchyr/BaseLib-StS2/releases) 下载 dll/pck/json 放入游戏 mods 目录

## 配置

把仓库根目录的 [Directory.Build.props.example](Directory.Build.props.example) 复制一份并改名为 `Directory.Build.props`（该文件已被 .gitignore 忽略，不会污染仓库），然后修改：

```xml
<GodotPath>C:/megadot/MegaDot_v4.5.1-stable_mono_win64.exe</GodotPath>
```

- `GodotPath`：改成你的 MegaDot **可执行文件**路径（不带引号）。
- 若游戏不在 Steam 默认位置，取消 `Sts2Path` 一行的注释并指向游戏安装目录
  （需包含 `data_sts2_windows_x86_64` 子目录）。

## 编译与安装

在 `HuTaoMod/`（含 csproj 的目录）打开终端：

```bash
# 1. 编译：生成 dll 并自动复制到游戏 mods 目录
dotnet build

# 2. 发布：额外用 MegaDot 打包 pck 到 mods 目录
dotnet publish
```

产物为三件套，位于游戏 mods 目录下的 `HuTaoMod/` 子目录：

```
<游戏mods目录>/HuTaoMod/
├── HuTaoMod.json
├── HuTaoMod.pck
└── HuTaoMod.dll
```

> mods 目录位置：默认在游戏安装目录的 `mods/`；Steam 版通常为
> `Steam/steamapps/common/Slay the Spire 2/mods/`。
> 也可以放在 MegaDot 编辑器目录下的 `mods/` 用于调试。

启动游戏 → Mod 列表启用 HuTaoMod 与 BaseLib → 新建一局即可选择胡桃。

## 已知适配点（首次编译/运行时如报错，按此排查）

以下 API 名称基于当前 BaseLib 公开源码推断，若与游戏/库新版本不符，均为**单点修复**（源码内已用注释标注）：

| 位置 | 内容 | 排查方法 |
|---|---|---|
| `Code/Cards/Support/BlossomSupport.cs` | `CreatureCmd.Damage(ctx, target, amount, ValueProp.Unpowered, source, null)` 参数顺序 | 实证参考社区 mod `rayinls/sts-1-to-2-card` 的 RedFireBreathingPower；`ValueProp` 若不在 Commands 命名空间按 IDE 提示补 using |
| `Code/Cards/Support/BlossomSupport.cs` | `Creature.Powers` 集合属性名 | 备选 BaseLib `PowerExtensions.GetPower<T>()` |
| `Code/Cards/Support/BlossomSupport.cs` | `CommonActions.Apply` 传负数减层（引爆/狂杀用） | 备选 `PowerCmd.Remove` 或对照原版移除能力的方法 |
| `Code/Powers/HuTaoFlowPowers.cs` | 回合开始钩子 `AfterSideTurnStart(context)` 签名 | 对照原版回合开始类 Power |
| `Code/Powers/HuTaoFlowPowers.cs` | 打牌钩子 `AfterCardPlayed(context, card)` 签名（香如故） | 对照原版同类 Power |
| `Code/Utils/ModActions.cs` | `CreatureCmd.LoseHp/Heal/GainBlock/GainEnergy/GainGold` 签名 | 反编译原版流失生命/回血/回能卡对照 |
| `Code/Cards/*.cs` | `StrengthPower` 位于 `Models.Powers` | 编译报错时改用 `Entities.Powers`（源码已标 ⚠） |
| `Code/Cards/*.cs` | `DynamicVars.Damage/Cards` 读取基础数值 | 不存在时按注释改写死数值 |
| `Code/Relics/HuTaoRelics.cs` | 战斗开始钩子名 `OnCombatStart` | 对照原版遗物 |
| `Code/Potions/HuTaoPotions.cs` | 使用钩子名 `OnUse` | 对照原版药水 |
| `Code/Cards/CommonBlossomCards.cs` 等 | `CombatState.Opponents` 取全场敌人 | 检查 CombatState 成员 |
| 本地化键格式 | 采用双键（snake_case + PascalCase 前缀）兜底 | 编译期 ModAnalyzers（STS001 等）会提示缺失键 |

`Krafs.Publicizer` 已开启，可直接访问游戏私有成员；ModAnalyzers 会在编译期校验本地化键，报错信息会直接指出缺失的键名。

## 美术素材说明

- 全部素材由 AI 原创生成：手绘暗黑奇幻风（对齐原版画风），角色立绘走可爱路线。
- 战斗立绘为**透明 PNG + 程序化演出**：`hu_tao_visuals.tscn` 里 8 段关键帧动画（呼吸/冲刺残影/施法发光/受击红闪/倒地淡出），
  加代码驱动的三只独立蝴蝶；动画名与时长必须和 `HuTao.cs` 的 `AttackAnimDelay` 等常量对齐。
  细节与「AI 帧动画」管线见 [docs/animation.md](docs/animation.md)。
- 83 张卡牌目前统一使用回退卡面（`card_portraits/card.png` 与 `big/card.png`）；可逐卡添加专属插画，命名 = 类名 snake_case.png（如 `hu_tao_strike.png`），无需改代码。
- 抠图边缘如有个别毛边，可用任意图像工具修整 `images/character/hu_tao.png`。
